# Alpha 3.2.0

Alpha 3.2.0 is an archived experimental control with 2,013,403,142 parameters.
It preserves the SmolLM2-1.7B-Instruct tokenizer, chat template, and configured
8,192-token context. Its selected checkpoint has 7,450,666 input-token
exposures. The lineage is retained for comparison and is not recommended for
deployment.

The checkpoint was initialized from SmolLM2-1.7B-Instruct and adapted using
additional data. The additional dataset and preparation process are not
released. See [MODEL_PROVENANCE.md](../MODEL_PROVENANCE.md) and
[RESULTS.md](RESULTS.md).
